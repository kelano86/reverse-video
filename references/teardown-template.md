# teardown.md template

Write plainly: short sentences, no hype, numbers over adjectives. If the user has a house voice
or style guide, use it. Every claim tagged (measured), (heard), (seen m:ss) or (inferred).
Cite images by relative path (`img/shots_01.jpg`). Keep sections that don't apply, with one line
saying why ("No music bed (measured): nothing to match").
